# Hospital con Aislamiento Sísmico en Puno, Perú

## Descripción del proyecto

Este proyecto corresponde a la revisión y análisis estructural de un hospital esencial ubicado en Puno, Perú, diseñado con sistema de aislamiento sísmico en base. La estructura contempla elementos de concreto armado, vigas colectoras sobre aisladores, pedestales, capiteles, losas macizas y un sistema de aislamiento orientado a reducir la demanda sísmica sobre la superestructura.

El objetivo técnico del proyecto es garantizar un adecuado desempeño estructural frente a eventos sísmicos severos, priorizando la continuidad operativa del hospital después de un sismo.

## Actividades desarrolladas

* Revisión de planos estructurales.
* Verificación de elementos de concreto armado.
* Evaluación de vigas colectoras sobre aisladores sísmicos.
* Revisión de pedestales y capiteles.
* Evaluación de cargas verticales y criterios sísmicos.
* Compatibilización técnica con otras especialidades.
* Revisión de detalles de acero de refuerzo.
* Análisis de criterios normativos aplicables a edificaciones aisladas.

## Elementos estructurales evaluados

* Vigas de concreto armado.
* Losas macizas.
* Pedestales de aisladores.
* Capiteles.
* Platea de cimentación.
* Sistema de aislamiento sísmico.
* Elementos de conexión entre subestructura y superestructura.
