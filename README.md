# Portafolio de Ingeniería Estructural

Caso de estudio desarrollado a partir de la tesis:

**“Evaluación de la resiliencia sísmica en un hospital esencial con aislamiento de base tipo LRB en la ciudad de Puno, 2026”**

Autor: Ing. Juan Americo Lopez Pizarro  
Universidad Nacional de Ingeniería  
Maestría en Ciencias en Ingeniería Civil con mención en Estructuras

## Contenido

- `index.html`: presentación ejecutiva del proyecto.
- `galeria.html`: archivo visual completo con búsqueda y filtros.
- `assets/images/`: 170 recursos recuperados y organizados por tema.
- `assets/css/`: sistema visual responsivo.
- `assets/js/`: navegación, ampliación de figuras y catálogo técnico.

## Publicación en GitHub Pages

1. Subir el contenido de esta carpeta a la rama `main`.
2. Abrir `Settings > Pages`.
3. En `Build and deployment`, elegir `Deploy from a branch`.
4. Seleccionar la rama `main` y la carpeta `/ (root)`.

El sitio no requiere compilación ni dependencias.
